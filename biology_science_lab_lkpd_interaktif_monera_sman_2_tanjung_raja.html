Catatan Teknis Lingkungan Canva Code:

Canva Code menjalankan aplikasi di sisi peramban (client-side) per perangkat siswa sehingga tidak menyimpan database server terpusat secara otomatis. Agar guru dapat mengumpulkan nilai seluruh siswa SMAN 2 Tanjung Raja dalam satu rekap, gunakan salah satu dari 2 metode resmi berikut:

Tempelkan URL Web App Google Apps Script Anda di bawah ini. Siswa dapat langsung menekan tombol Kirim ke Rekap Guru pada halaman Hasil Pembelajaran.

Lihat Kode Google Apps Script Siap Pakai (Klik untuk membuka) 
function doPost(e) {
  var ss = SpreadsheetApp.getActiveSpreadsheet();
  var sheet = ss.getSheetByName("REKAP_SISWA") || ss.insertSheet("REKAP_SISWA");
  var data = JSON.parse(e.postData.contents);
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["Waktu", "Nama Siswa", "Kelas", "No Absen", "Kelompok", "Tanggal", "Nilai Akt 1", "Nilai Akt 2", "Nilai Akt 3", "Nilai Evaluasi", "Benar", "Salah", "Nilai Akhir", "Kategori"]);
  }
  sheet.appendRow([new Date(), data.nama, data.kelas, data.absen, data.kelompok, data.tanggal, data.akt1, data.akt2, data.akt3, data.evaluasi, data.benar, data.salah, data.nilaiAkhir, data.kategori]);
  return ContentService.createTextOutput(JSON.stringify({status: "success"})).setMimeType(ContentService.MimeType.JSON);
}

Metode 2: Penggabungan File Excel Siswa (.xlsx)

Setiap siswa mengunduh file REKAP_LKPD_MONERA_SMAN2_TANJUNG_RAJA.xlsx dari perangkat masing-masing lalu mengirimkannya lewat Google Classroom / WhatsApp Grup. Pada halaman Hasil Pembelajaran, guru dapat memilih banyak file .xlsx siswa sekaligus untuk digabung menjadi satu rekap master kelas!
